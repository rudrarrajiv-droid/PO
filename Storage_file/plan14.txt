STEP 1 — GLOBAL SEARCH
============================================================

Use the existing search box from Phase 2.

Placeholder:

"Search PO No., Customer, Consignee, Artwork or Item"

Search must support partial matching.

Search fields:

PO NO.

CUSTOMER NAME

CONSIGNEE

ARTWORK NO.

ITEM NAME

Example:

If the item is:

01U512140 TEAR HERE

Typing:

2140

should return that item if the application/database supports the
required matching.

Typing:

512

should also find it.

Typing:

TEAR

should also find it.

Do NOT require the complete value.

============================================================
STEP 2 — SEARCH BEHAVIOUR
============================================================

Search should update the visible PO table.

Do not reload the complete application unnecessarily.

Do not modify the stored PO records.

Do not create duplicate search indexes/documents unless genuinely
required by the existing database architecture.

If Firestore querying has limitations:

Use the safest existing application approach.

Do NOT introduce an external search service.

============================================================
STEP 3 — CUSTOMER FILTER
============================================================

Add a Customer filter.

The filter should allow selecting a customer from existing PO data.

When selected:

Only that customer's POs appear.

When cleared:

All POs return.

Do not create customer-specific collections.

============================================================
STEP 4 — PO DATE FILTER
============================================================

Provide:

PO Date From

PO Date To

Examples:

01/07/2026 → 31/07/2026

The result must contain only POs whose PO Date falls inside the selected
range.

If only From is provided:

show records from that date onward.

If only To is provided:

show records up to that date.

============================================================
STEP 5 — DELIVERY DATE FILTER
============================================================

Provide:

Delivery Date From

Delivery Date To

Use the actual Delivery Date stored in the PO.

Do not calculate or modify Delivery Date.

IMPORTANT:
