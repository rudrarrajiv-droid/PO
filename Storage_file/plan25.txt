============================================================

============================================================
STEP 5 — BALANCE VALIDATION
============================================================

Verify the imported values against the approved PO logic:

CLOSING BAL
=
OPN QTY + IN QTY - OUT QTY

Example:

OPN QTY = 1000

IN QTY = 300

OUT QTY = 200

Expected Closing:

1100

If Excel says:

1050

flag:

BALANCE MISMATCH

Do NOT silently change Excel data.

Do NOT silently change the formula.

============================================================
STEP 6 — VALUE VALIDATION
============================================================

Validate VALUE using the already approved PO business logic.

DO NOT invent a new formula.

If the approved logic is based on:

CLOSING BAL × RATE

then validate against that logic.

If the existing approved logic differs:

use that existing logic.

If the source workbook contains a value that does not match the approved
business calculation:

FLAG THE ROW.

Do NOT automatically overwrite the source value.

============================================================
STEP 7 — PO NUMBER VALIDATION
============================================================

PO NO. must not be blank.

ALREADY EXISTS IN DATABASE

POSSIBLE CONFLICT

DO NOT overwrite the existing PO.

DO NOT update it.

DO NOT delete it.
